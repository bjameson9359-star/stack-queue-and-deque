Breakdown:
There are six classes of 3 linked list 3 arrays. First 2 are the two versions of the queue, the linked list version has 4 variables and focuses on tracking the head and tail node to add to the lend by setting tails next to the new element and removing the head when removing elements.(I know not pop and push are for the stack but apparently c++ built in que uses the same terms for both so I mimicked that.) Most methods are O(1) because they just use a pointer whereas print and empty are O(n) because it needs to navigate the full list. Next is the array version which has 5 variables. It uses 2 ints to track head and tail, 2 for max size and current size, and 1 double array for the data. Works mostly the same just instead of using next it’s tail and head ++ method time complexity is the same.
The next pair is the stack which is even simpler. The stack list only tracks head and next and adds by making a new head that points to the new one and removing by push the head to it’s next value. This is O(1). The other two methods empty and print are also O(n) because it needs to check every element. Note the print is simpler for the array version of this compared to the loop for the array que because this can just use 0 as the head and doesn’t need to worry about tracking head and accounting for looping around the array.
Lastly is the dequeue or deque (idk I found both spellings). The linked list was the first one I wrote and it works by tracking the same things as the queue but has a previous and methods that can remove both the top and the bottom of the linked list. In code it is the same thing just + one method that is O(1), the array implementation is also very close to being the same as the queue it also just have one more O(1) algorithms to remove the bottom of the array and it also has the dual pointer tracking and looping of the queue array.
